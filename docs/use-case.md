# AIMS Mini - Use Case Description

## Actors
- Customer: Người mua DVD.
- Store Manager: Người quản lý cửa hàng.

## Main Use Cases
- View DVD information: Xem thông tin DVD.
- Search DVD by title: Tìm kiếm DVD theo tiêu đề.
- Add DVD to cart: Thêm DVD vào giỏ hàng.
- Remove DVD from cart: Xóa DVD khỏi giỏ hàng.
- View cart: Xem giỏ hàng.
- Place order: Đặt hàng.

## Description
Customer can browse DVDs, search for DVDs by title, add or remove DVDs from the cart, view the cart, and place an order.
